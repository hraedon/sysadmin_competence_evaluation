EXECUTIVE SUMMARY
-----------------
Current backup architecture: nightly full backups of all production systems to
LTO tape, with a daily courier shipment to an offsite tape vault. Retention
policy: 30 days on-site, 1 year offsite in vault.

Proposed architecture: retain the existing on-site backup appliance (BACKUP01)
as the primary restore target; replace the offsite tape vault with replication
to a cloud object-storage service.

Estimated annual savings: $42,000 in tape media, courier contracts, and vault
fees.

PROPOSED DESIGN
---------------
Primary backup target:
  - Existing on-prem backup appliance (BACKUP01)
  - Retention: 30 days

Offsite copy:
  - Service: StorCloud Object Storage
  - Region: primary region
  - Bucket type: Object Lock / immutable bucket with Compliance-mode retention
  - Minimum retention: 30 days
  - Replication: Nightly upload of previous day's backup files from BACKUP01
  - Encryption: TLS 1.3 in transit, AES-256 at rest (managed by StorCloud)

Network:
  - Existing internet breakout, 1 Gbps symmetric
  - Traffic routed through the production perimeter firewall

Authentication:
  - Single service account: svc_backup_replicate@corp.local
  - Credential stored in a file on BACKUP01
  - Permissions: read/write access to the StorCloud bucket

Monitoring:
  - Backup job success/failure alerts via existing monitoring stack
  - StorCloud console dashboard for storage utilization

Restore procedure:
  - Identify required restore points in backup catalog
  - Download restore points from StorCloud to BACKUP01
  - Perform restore from BACKUP01 to target system

RATIONALE
---------
1. Tape recall is slow (next-business-day minimum, often 24-48 hours). Cloud
   storage offers API-driven access that can begin a restore within minutes.

2. Object Lock provides immutable backups that cannot be deleted or modified
   during the retention period, protecting against ransomware.

3. StorCloud manages underlying durability, availability, and geographic
   redundancy.

4. Cost reduction aligns with the FY2027 budget target of 8% infrastructure
   savings.

RISK ACKNOWLEDGMENTS
--------------------
- Internet dependency for offsite recovery
- Egress charges apply when restoring from cloud
- Single service account is a concentration of access
- Cloud provider outage could temporarily block offsite restores

REQUESTED DECISION
------------------
Approve implementation for all production systems beginning 2026-08-01.

Implementation plan:
  - Week 1: Configure StorCloud bucket, Object Lock, and service account
  - Week 2: Replicate existing on-site backups to cloud bucket
  - Week 3: Cut over nightly offsite copy from tape courier to cloud replication
  - Week 4: Decommission offsite tape vault contract
